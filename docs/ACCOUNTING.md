# 月度统计约定

- 名称必填，预计价格可留空。未知金额显示待补价格，不当作零元商品。
- 金额内部以整数分存储；支持零金额，拒绝负数、超过两位小数和非数字。
- 计划总额：当月新建和用户明确保留到当月的估价合计。购买后原估价仍保留。
- 已记录消费：按购买日期归属的实付金额，包括未先做计划的补记消费。
- 剩余待购：月度状态为待考虑/转到后月的估价。历史月份保留当时尚未购买的状态。
- 本月预计合计：已记录消费 + 剩余待购，不与计划总额重复相加。
- 放弃的计划金额：明确选择不买的估价，不称为实际省钱。
- 同一条心愿每个月最多一个计划成员、最多一笔真实购买。跨月不改原添加日期。
- 例如：一月计划 500，二月保留后花 450；一月实际为 0，二月实际为 450、待购为 0。
- 中间未打开的月份不会自动复制计划。月报首次提醒后，往月待处理列表仍然可见。
- 修改预计价格只调整最新计划月份，不改较早的保留快照。修改真实付款金额/日期重新归属实际消费。
- 选择不买会结束最后一个计划月份的待购状态，并保留历史；删除会删除整条记录并重算所有关联月份。
- 备份先完整校验，再确认覆盖。单个快照提交，写入成功后才更新内存；恢复前快照额外保存在 Hive 的 `before_restore` 键中。

仅统计用户在此应用记录的内容，不宣称覆盖全部个人支出。
